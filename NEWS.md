# ecosanctuary 0.1.0

* Added a portable CSV question-index format and folder-to-index scaffolding.
* Added complete-bank validation for metadata, fragments, chunk labels,
  variable prefixes, solution blocks, and answer helpers.
* Added explicit, filtered, and reproducible random question selection.
* Added Moodle XML, student HTML/PDF, teacher HTML/PDF, and selection-manifest
  generation.
* Added numerical, short-answer, single-choice, and multiple-choice helpers.
* Added an example bank, reference documentation, vignettes, tests, and CI.
