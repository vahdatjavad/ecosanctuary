# ecosanctuary: reusable assessment question banks

The package separates reusable rendering logic from course-specific
content. Start with
[`create_question_index()`](https://vahdatjavad.github.io/ecosanctuary/reference/create_question_index.md),
check a bank with
[`validate_question_bank()`](https://vahdatjavad.github.io/ecosanctuary/reference/validate_question_bank.md),
and build outputs with
[`build_quiz()`](https://vahdatjavad.github.io/ecosanctuary/reference/build_quiz.md).
Use the four
[answer_helpers](https://vahdatjavad.github.io/ecosanctuary/reference/answer_helpers.md)
inside question fragments.
